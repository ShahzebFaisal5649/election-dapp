# Election DApp

A decentralized voting application built on Ethereum blockchain using Solidity smart contracts.

## 📋 Overview

This DApp (Decentralized Application) allows users to participate in transparent and tamper-proof elections on the blockchain. It demonstrates the implementation of a voting system using smart contracts, ensuring immutability and transparency.

## 🚀 Features

- **Blockchain-based voting**: Votes are recorded on the Ethereum blockchain
- **Transparent results**: All votes are publicly verifiable
- **Immutable records**: Once cast, votes cannot be altered
- **Smart contract powered**: Election logic handled by Solidity contracts

## 🛠️ Tech Stack

- **Solidity**: Smart contract development
- **Truffle**: Development framework
- **Web3.js**: Blockchain interaction
- **HTML/CSS/JavaScript**: Frontend interface
- **Ganache**: Local blockchain for testing

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/ShahzebFaisal5649/election-dapp.git
cd election-dapp
```

2. Install dependencies:
```bash
npm install
```

3. Start Ganache (local blockchain)

4. Compile smart contracts:
```bash
truffle compile
```

5. Deploy contracts:
```bash
truffle migrate
```

6. Run the application:
```bash
npm run dev
```

## 📝 Usage

1. Connect MetaMask to your local Ganache network
2. Import accounts from Ganache into MetaMask
3. Open the application in your browser
4. Cast your vote for a candidate
5. View real-time election results
